# Projects

Learner contracts, one directory per project. Every project has a `README.md` that
starts like this — the `Authors:` line is what decides who can change the project:

```markdown
# BTC daily candles

Authors: @your-github-user

Which dataset these contracts describe, who consumes it, and what they may rely on.
```

Start by copying the closest contract from `../reference/ingestion_contracts/`. To work
on an existing project, open a pull request that only adds your handle to its `Authors:`
line. See [CONTRIBUTING.md](../CONTRIBUTING.md).
